A sprinkler system set to "15 minutes every day" is the most common lawn mistake in the suburbs. It feels responsible. It grows shallow roots, fungus and a water bill.

## The Goal

**About an inch of water a week, counting rain.** Give it in one or two deep soaks, not seven sips. Deep, rare watering pushes roots down, where they can find water in a dry spell.

## The Tuna Can Test (15 Minutes, Once)

1. Put 4–6 empty tuna or cat food cans around one zone: some near the heads, some in between.
2. Run that zone for 15–20 minutes.
3. Measure the water in each can with a ruler and average them.
4. Do the math. If 20 minutes put down a quarter inch, 40 minutes gives about half an inch.
5. Repeat for each zone. They're never the same.

Uneven cans tell you something too: a clogged or misaimed head. Fix it before you crank up the time.

## Set It Like This

- **Twice a week, about half an inch each time** (adjust per zone using your can test).
- **Early morning,** done by about 10am.
- **Rain counts.** Use a rain sensor, or check [should I water this week?](/resources/should-i-water-my-lawn/) before you let it run.
- **Shade zones need less.** Shady grass dries slower.
- **Sloped zones:** split the time into two shorter cycles back to back so water soaks in instead of running off.

## Through the Year

- **Spring:** usually off. Rain does it.
- **Summer:** this schedule.
- **September seeding:** new seed needs a totally different schedule. See [how to water new grass seed](/guides/how-to-water-new-grass-seed/).
- **Fall:** dial it back as it cools, then shut it off and drain the system before the first hard freeze.
